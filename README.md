# 📜 Alchemist's Touch

**Alchemist's Touch** é um jogo de gerenciamento e puzzle desenvolvido na **Unity**. No papel de um alquimista em um mercado noturno místico, o jogador deve combinar ingredientes exóticos para atender aos pedidos de clientes monstruosos antes que o tempo se esgote.

## 🧪 Sobre o Jogo

O projeto foca em mecânicas de **Drag & Drop** (Arrastar e Soltar) e um sistema lógico de combinações de itens. O jogo utiliza uma estética em Pixel Art com temática de fantasia sombria e Halloween.

### Funcionalidades Atuais:

- ✅ Sistema de Arrastar e Soltar (Drag & Drop) funcional.
- ✅ Caldeirão com reconhecimento de ingredientes via IDs.
- ✅ Sistema de Receitas (ScriptableObjects) para criação de poções.
- ✅ Menu Principal funcional com transição de cenas.
- ✅ Gerenciamento de Assets via Git LFS.

## 🚀 Como Rodar o Projeto

1.  Certifique-se de ter o **Git LFS** instalado em sua máquina.
2.  Clone este repositório:
    ```bash
    git clone https://github.com/SEU_USUARIO/Alchemist-s-Touch.git
    ```
3.  Abra a pasta do projeto no **Unity Hub**.
4.  Certifique-se de que todas as cenas foram adicionadas ao _Build Settings_.
5.  Abra a cena `SceneMenuPrincipal` e divirta-se\!

## 📖 GDD (Game Design Document) - Resumo

O loop principal consiste em:

1.  **Observar** o pedido do cliente.
2.  **Consultar** o Grimório de receitas.
3.  **Misturar** os itens corretos no Caldeirão.
4.  **Entregar** o resultado para ganhar tempo e moedas.
